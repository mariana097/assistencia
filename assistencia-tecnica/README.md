# Assistência Técnica

Projeto de gerenciamento de assistência técnica usando Python, Flask e SQLAlchemy.

## Estrutura

- `app/`: código da aplicação
- `tests/`: testes unitários
- `requirements.txt`: dependências
- `run.py`: ponto de entrada para executar o servidor Flask

## Como executar

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Execute a aplicação:

```bash
python run.py
```

3. Execute os testes:

```bash
pytest
```
